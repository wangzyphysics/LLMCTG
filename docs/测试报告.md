# LLM中文文本生成系统测试报告

## 1 测试范围

测试覆盖 V1.0 的配置加载、等级解析、请求校验、文本清洗、句子切分、重复率、模板生成、可读性评估、批处理错误隔离和报告文件输出。由于本地模型权重不随软件分发，Transformers 后端仅验证参数与依赖检查，实际模型效果由部署方结合指定模型另行验收。

## 2 测试环境

基础测试使用 Python 3.10 或更高版本，采用 UTF-8 文件编码。测试不依赖网络、GPU或外部模型，确保登记材料和软件包在普通计算机上可完成核心流程验收。

## 3 验收项目

| 编号 | 测试内容 | 预期结果 |
|---|---|---|
| T01 | 中英文和数字等级解析 | 转换为三个统一阅读等级 |
| T02 | 空主题和数量越界 | 拒绝请求并给出清晰错误 |
| T03 | 中文空格与换行规范化 | 保留自然段并清理多余空白 |
| T04 | 模板生成 | 产生标题、正文和评估结果 |
| T05 | 空文本评估 | 判定不通过并提示文本为空 |
| T06 | 重复文本评估 | 计算重复率并生成修改建议 |
| T07 | 批量任务部分失败 | 正常任务继续，异常写入错误文件 |
| T08 | 报告导出 | 生成 JSONL、JSON、CSV 和 HTML |
| T09 | 固定随机种子 | 相同请求生成结果可复现 |
| T10 | 非法 JSONL | 指出文件与具体错误行号 |

## 4 通过准则

自动化测试应全部通过；演示命令退出码为零；输出目录至少包含 `articles.jsonl`、`summary.json`、`summary.csv` 和 `report.html`；中文无乱码；单条异常不得导致已经生成的结果丢失。

## 5 已知限制

规则评分依赖字符和篇章统计，不能独立判断专业事实真伪。模板后端用于工作流演示，不代表大模型生成质量。本地模型的速度、显存占用和内容表现由模型规模、量化方式、设备与驱动共同决定。
