# LLM中文文本生成系统部署说明

## 1 基础部署

进入软件根目录，执行 `python -m pip install -e .`。安装完成后可使用 `llmctg --version` 查看版本，使用 `llmctg demo --output output/demo` 运行验收演示。若不希望安装，也可把 `src` 加入 `PYTHONPATH` 后执行 `python -m llmctg`。

## 2 本地模型部署

执行 `python -m pip install -e ".[llm]"` 安装可选依赖。将已获授权且与 Transformers 兼容的模型放在本地目录，在配置中填写 `model_path`，并把后端改为 `transformers`。使用 LoRA 微调结果生成时，可在配置中填写 `lora_path`，或在生成命令中传入 `--lora-path`。CPU 环境建议选用较小模型；CUDA 环境应确保 PyTorch 与显卡驱动匹配。

## 3 运维建议

生产运行前应先用少量任务验证模型和设备。批处理输出应放在独立日期目录并定期备份。出现显存不足时，可降低最大生成令牌数或更换较小模型。公开发布生成内容前应完成人工审核。
